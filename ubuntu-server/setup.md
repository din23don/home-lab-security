# Ubuntu Server Setup

## Environment

- Hypervisor: VirtualBox
- Operating system: Ubuntu Server 24.04 LTS
- Hosts OS: Windows 11

## Instalation

Ubuntu Server was installed as virtual machine for cybersecurity home lab practice.

## Configuration

- Virtual machine created in VirtualBox
- Network configured using apt
- System update using apt
- Internet connectivity tested

## Verification Commands

System information:

```bash
hostnamectl

Network information:

```bash
ip a

System update:

```bash
sudo apt update
sudo apt upgrade -y
